# 任务时间与提醒
项目侧栏“新建定时任务”可一次填写任务和时分，官方入口创建后可在详情“任务时间与提醒”补充。仅日期用于原日历和视图，具体时间用于提醒、同步和打卡。
AI 使用 `pushgo_create_task`、`pushgo_set_task_times`。创建响应不明时使用原 op_id 查询 `pushgo_get_task_operation`，禁止更换标识重建；仅日期或待处理不能报告为已安排精确提醒。
调用者必须有任务写入和插件管理权限。调用授权仅加密短存最多 5 分钟，终态清除；写入前重新核对调用者权限。
原专属时间仅在一致且窗口未开放时迁移，差异进入核对。写前检查、写后验证不能替代跨系统原子事务。
